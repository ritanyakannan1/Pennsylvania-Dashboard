This project is an interactive Tableau dashboard that analyzes sales and profitability for a retail business using 9,993 Superstore orders from 2014 to 2017. It tracks yearly sales and profit KPIs, breaks performance down by category, sub-category, customer segment, and state, and includes a 12-month sales forecast with 95% confidence bands (MASE 0.51) and a What-If sheet with a Discount Cap parameter for testing how discount limits could affect profit. The analysis showed about $2.3M in total sales with a 12.5% profit margin, but Furniture earned only about $19K in profit on $742K in sales, with Tables and Bookcases operating at a loss, leading to recommendations to review discounting on those lines and investigate low-profit states like Texas. Built with Tableau Desktop; the packaged workbook (.twbx) includes the data.
